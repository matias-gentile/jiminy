# Jiminy

Un acompañante para empezar a usar Claude sin saber nada de IA. Vive en Cowork, la
app de escritorio de Claude: te entrevista, arma tu espacio de trabajo, te deja tus
primeras habilidades y aprende de cada corrección.

> **Estado:** en construcción. Estamos en la Fase 0, las pruebas en Cowork.
> Todavía no hay nada para usar todos los días.

## Qué hay acá

| Ruta | Qué es |
|---|---|
| `docs/diseno.md` | El diseño completo: decisiones, arquitectura, ciclo de mejora y plan |
| `docs/fase-0.md` | Las pruebas en Cowork que se hacen antes de construir el núcleo |
| `biblioteca/indice.md` | Fuentes externas curadas, fijadas a una versión |
| `plugins/jiminy-prueba/` | Plugin mínimo para la Fase 0. Se borra cuando terminen las pruebas |

## Probarlo (solo Fase 0)

1. Instalá Claude Desktop con un plan que incluya Cowork.
2. Andá a *Customize > Plugins > Add marketplace* y pegá `matias-gentile/jiminy`.
3. Instalá `jiminy-prueba` y seguí `docs/fase-0.md`.
